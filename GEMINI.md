# Superpowers Integration

This repository is equipped with the **Superpowers** skill system (`https://github.com/obra/superpowers`).

- **Bootstrap**: Start by referencing `.agents/skills/using-superpowers/SKILL.md`.
- **Workflow**:
  - `brainstorming`: Invoke before writing code or making major design decisions.
  - `writing-plans` & `executing-plans`: Use for structured plan development and execution.
  - `systematic-debugging`: Invoke when investigating and fixing bugs.
  - `test-driven-development`: Follow red/green/refactor TDD cycles.
  - `subagent-driven-development`: Execute multi-step tasks using subagents.
  - `verification-before-completion`: Verify implementations before marking complete.

# DLNA 렌더러 호환성 기록

실기기에서 확인한 결과를 기록한다. 새 렌더러를 시험하면 행을 추가하고, 앱 버전이나 펌웨어가 바뀌면 다시 확인한다.

## 확인 방법

1. 설정 탭에서 스피커를 선택하고 아래 곡 유형을 하나씩 재생한다.
2. 각 항목을 `O`(정상), `X`(실패), `△`(부분 동작, 비고에 설명), `-`(미확인)로 적는다.
3. 실패하면 설정 탭의 디버그 로그에서 `DLNA_`, `UPNP_SOAP`, `PROXY` 태그 로그를 비고에 요약한다.

| 항목 | 확인 내용 |
| --- | --- |
| FLAC 재생 | LOSSLESS(기본) 곡이 끝까지 재생되고 다음 곡으로 넘어가는가 |
| DASH 재생 | 음질 설정을 HI_RES로 두었을 때 재생되는가 |
| 탐색 | LOSSLESS 재생 중 진행 바로 위치를 옮길 수 있는가 |
| 메타데이터 | 스피커(또는 앱) 화면에 제목, 아티스트, 커버가 보이는가 |
| 볼륨 | 앱 슬라이더와 화면이 꺼진 상태의 볼륨 키로 스피커 볼륨이 한 단계씩 바뀌는가 |
